# detector
## 输入：jpeg压缩图像

## 实现功能：
- 检测图像中的ColorBlock，获得圆形色块的颜色，获取正方形色块的关键点，颜色
- 绘制正方形色块在图像上
- 同时用PnP解算获取每个正方形色块关键点的空间位姿，orientation
- 发布关键点位姿信息，颜色信息，orientation

使用局部自适应阈值分割出二值图像，后面形态学操作开运算一次，

又出现问题了，黄色和浅灰色的轮廓断断续续的，先用3x3的卷积核闭运算一次试试
黄色和棕色还是有点，加大力度，不用闭运算了，直接上膨胀

噪点和轮廓连续性是主要的问题现在，如果膨胀的话，噪点会是轮廓变形。先试试用外接最小矩形来看能不能修正黄色他们的轮廓

可以连接起来，但是因为黄色色块的轮廓不稳定，导致其矩阵会变大变小，影响检测，再试试膨胀看看.直接大核膨胀的话，会导致噪声与轮廓连在一起，其他色块也开始变形了.

噪声还是太ex了，先考虑去完噪声后再进行膨胀连接。两次开运算就去完噪声了，现在考虑怎么把他们连接起来

不行，用两次开运算虽然噪声没了，但是轮廓的间隙太大，连接不上了。
重新分析一下现状，现在使用一次33开运算+一次55闭运算，黄色轮廓经常变大小，米色偶尔变，其他基本不变
为什么会这样？因为他们的轮廓不是很连续，为什么不连续？可能是gray值与白色相差不大，那黄色和米色单独用HSV检测试试

很成功，以后难分割的就单独把他们用HSV分割出来再合并

用近似和最小外接矩阵来获得矩形

现在又有新问题，如果摄像头是在左右两边，色块的轮廓会变大变小，这个先放着

然后就是剔除其他轮廓，先用长宽比，再用对角线过圆点，最后用矩形中心到圆点的距离来剔除
