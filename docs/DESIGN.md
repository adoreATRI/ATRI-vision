# detector
## 输入：jpeg压缩图像

## 实现功能：
1. 检测图像中的ColorBlock，获得圆形色块的颜色，获取正方形色块的关键点，颜色
2. 同时用PnP解算获取每个正方形色块和圆色块关键点的空间位姿
3. 发布关键点位姿信息，颜色信息，orientation

#### 图像预处理
采用中值滤波(双边滤波使用会使速度明显减慢，而且效果并不明显提升)
主要使用局部自适应阈值(均值)进行分割，但是黄色和米色在此分割不好，所以用两个HSV阈值对其进行单独分割
形态学操作则使用小核进行一次开运算稍微去噪保留边缘，闭运算后再用中值滤波进行第二次去噪，效果不错

#### 色块检测
后面所有操作以找到圆形色块为前提，圆形色块检测最外层轮廓和圆心

矩形色块筛选：面积，长宽比，对角线是否过圆心，到圆心距离

#### 颜色特征检测
ab差异可以检测大部分颜色，但对棕色和米色效果不好，故采用锐度等加权检测
